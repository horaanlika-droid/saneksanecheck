# 📷 SANEK — портфолио фотографа (Telegram Mini App + бот)cheeeeeeck

Веб-приложение в Telegram в современном лаконичном стиле + админ-бот, который полностью управляет контентом.

- **Мини-приложение**: hero-экран, о фотографе, работы (разделы → фотосеты), избранное, услуги с ценами, выставки и награды, контакты, форма записи. Два языка (RU/EN).
- **Бот**: меняет тексты, цены, услуги, соцсети, телефон; загружает фотосеты и отдельные фото; прикрепляет фото к услугам; присылает заявки; делает бэкапы. Всё применяется на сайте мгновенно — лезть в код не нужно.

## Как это устроено

Один процесс (`python -m app.main`) запускает сразу два компонента:

| Компонент | Что делает |
|---|---|
| FastAPI-сервер | отдаёт мини-приложение, JSON API, фотографии |
| aiogram-бот (polling) | админ-панель, загрузка фото, уведомления о заявках; при сбое связи с Telegram перезапускается сам с backoff |

Данные хранятся в SQLite (`data/app.db`), фото — в `data/uploads/`. Для каждого фото бот сохраняет оригинал + превью и запоминает Telegram `file_id` — если файл пропадёт с диска, сервер сам восстановит его из Telegram.

При каждом старте бот **автоматически пушит**: команды, описание и кнопку меню «📷 Открыть портфолио». В BotFather ничего настраивать не нужно.

## 🚀 Деплой на хостинг (BotHost и др.)

1. Залейте репозиторий на хостинг (или подключите его к GitHub-репозиторию).
2. Укажите команду запуска:
   ```
   python -m app.main
   ```
3. Задайте переменные окружения — **достаточно только этих**:
   | Переменная | Пример | Что это |
   |---|---|---|
   | `BOT_TOKEN` | `123456:ABC...` | токен бота от @BotFather |
   | `ADMIN_IDS` | `123456789` | ваш Telegram ID (узнать: @userinfobot). Несколько — через запятую |
   | `WEBAPP_URL` | `https://xxx.host.com` | публичный адрес приложения (даёт хостинг после деплоя) |

   > `WEBAPP_URL` можно вообще не задавать: после первого внешнего запроса к сайту адрес определяется автоматически (по заголовкам Host / X-Forwarded-*) и сохраняется в базе, а кнопка меню бота устанавливается сама. Также его можно добавить позже через бота: Админка → 👤 Профиль → 🔗 Адрес веб-приложения.

4. Убедитесь, что папка `data/` переживает перезапуски (persistent disk / volume). Если хостинг без постоянного диска — периодически забирайте `/backup` из бота.

Всё остальное (команды, кнопка меню, описания) настроится само при старте.

### Docker

```bash
cp .env.example .env   # заполнить BOT_TOKEN, ADMIN_IDS, WEBAPP_URL
docker compose up -d --build
```

### Локальный запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить
python -m app.main
# сайт: http://localhost:8000
```

Без `BOT_TOKEN` запустится только сайт (удобно для вёрстки), бот просто не стартует.

## 🤖 Гид по боту (для владельца)

Откройте бота → `/admin`. Разделы:

- **👤 Профиль и контакты** — имя/бренд, слоган, «о себе», факты, город, телефон, Telegram, WhatsApp, Instagram, Behance, email, стаж/цифры, валюта, аватарка, фото главного экрана, вкл/выкл формы записи, адрес приложения.
- **🗂 Разделы работ** — верхние категории (Editorial, Fine Art, Wedding…). Создание, переименование, порядок, удаление.
- **📸 Фотосеты** — серии внутри раздела (съёмка, выставка, проект): название, описание, локация, год, видимость, порядок. **Загрузка фото**: «📥 Загрузить фото» → присылайте по одному или альбомом → «✅ Готово». Бот сам скачает, сожмёт и привяжет фото — они сразу появятся на сайте.
- **🖼 Избранное** — отдельные фото вне сетов (лента Selected на сайте): загрузка, подписи, порядок, удаление.
- **💼 Услуги** — название, описание, **цена**, уточнение цены, длительность, вкл/выкл, порядок. «🖼 Обложка» — главное фото, «📥 Прикрепить фото» — галерея услуги.
- **🏆 Выставки** — выставки, фестивали, награды: название, место, год, описание.
- **💬 Заявки** — заявки из формы записи: просмотр, принять/отклонить. Новые заявки также прилетают в личку админам с кнопками.
- **👥 Администраторы** — добавить/убрать админов по Telegram ID.
- **📊 Статистика**, **💾 Бэкап** (присылает zip: база + все фото), **📷 Открыть приложение**.

Команды: `/start` `/app` `/admin` `/leads` `/backup` `/cancel`.

Любое фото на сайте можно **подписать, сделать обложкой, переместить или удалить** — откройте его в боте через список фотографий.

## 🗂 Структура проекта

```
app/
  main.py          # точка входа: веб-сервер + бот
  config.py        # переменные окружения
  db.py            # SQLite: разделы, сеты, фото, услуги, выставки, заявки
  seed.py          # стартовое демо-наполнение (меняется через бота)
  images.py        # ресайз фото и превью
  server.py        # FastAPI: /api/site, /api/album, /api/booking, /uploads
  seed_assets/     # демо-фото для первого запуска
  bot/
    bot.py         # создание бота, автопуш команд/меню
    notify.py      # уведомления админам
    keyboards.py   # все клавиатуры
    states.py      # FSM-состояния
    media.py       # скачивание фото из Telegram
    handlers/      # start, profile, categories, albums, photos, services, exhibitions, leads, misc
frontend/
  index.html app.js styles.css   # мини-приложение (без сборки)
data/              # база и фото (на хостинге — persistent volume)
Dockerfile  docker-compose.yml  .env.example
```

## ❓ FAQ

**Фото грузятся медленно?** — Бот автоматически делает превью (900px) для сеток и полные версии (до 2048px) для просмотра.

**Потерялись фото после переезда?** — Сервер восстановит их из Telegram по сохранённым file_id при первом запросе (нужен запущенный бот с тем же токеном).

**Как сменить демо-контент?** — Всё через бота: тексты — «Профиль», фото — «Фотосеты»/«Избранное», цены — «Услуги». Соцсети и телефон по умолчанию подставные (`username`, `+7 (900) 000-00-00`) — поменяйте первым делом.

**Нужен ли домен/SSL?** — Для кнопки меню и Mini App нужен публичный `https://` адрес — его выдаёт хостинг (это и есть `WEBAPP_URL`).
